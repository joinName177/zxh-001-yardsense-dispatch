# YardSense Dispatch

YardSense Dispatch is a durable, local-first yard operations board. Dispatchers create equipment and safety tickets, assign zone-qualified workers, advance a controlled workflow, add operations notes, and reopen the process with the JSON document intact.

Run locally with `go run ./cmd/yardsense -data ./data/yardsense.json`, then open `http://localhost:8080`. Build Docker with `./build_benzhi_docker.sh linux/arm64` or `./build_benzhi_docker.sh linux/amd64`.
